Rapid Classifier

Project Library

Scan folders automatically, track progress across deployment sites, and archive everything to a local database.

Opening it the first time

macOS

Open the .dmg, drag TRAAACE to Applications, then right-click it and choose Open (and Open again in the dialog).

If macOS says the app is damaged, open Terminal and run xattr -dr com.apple.quarantine /Applications/TRAAACE.app

Windows

If SmartScreen appears, click More info → Run anyway.

TRAAACE needs Microsoft WebView2, which Windows 10 and 11 already include.

Linux (Ubuntu)

The simplest is the .deb: sudo apt install ./TRAAACE_*_amd64.deb

For the AppImage, run chmod +x TRAAACE_*.AppImage first. On Ubuntu you may also need sudo apt install libfuse2 (libfuse2t64 on 24.04).
