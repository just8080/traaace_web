TRAAACE for NVIDIA graphics cards

A test version for Windows computers with an NVIDIA graphics card. The AI species suggestions can run on the graphics card instead of the processor, which can make scans much faster. It is new, so please tell us how it goes.

Is it for you?

Check these before downloading. If you are not sure, use the normal version: it works on every computer.

You need

  • Windows 10 or 11, 64-bit.
  • An NVIDIA graphics card: GeForce GTX 900 series or newer, or any RTX card (for example GTX 1060, RTX 2060, RTX 3060, RTX 4070).
  • An NVIDIA driver from 2023 or later (version 528 or newer). To check, open Command Prompt and type nvidia-smi: the driver version is near the top.
  • About 7 GB of free disk space while it installs (about 3.5 GB afterwards).

Not for you (yet)

  • Mac or Linux: use the normal version. Macs already use their own graphics for the AI.
  • Computers without an NVIDIA card, like most laptops with Intel or AMD graphics. It still works there, but it is no faster than the normal version.
  • AMD Radeon or Intel Arc graphics cards.

How it works

It is the normal TRAAACE 0.6.1 with one extra choice when you set up the AI add-on.

The graphics card add-on

  • When you set up AI, choose NVIDIA graphics card instead of Standard.
  • It is a large download, about 3.5 GB. Most of it is NVIDIA's own CUDA software, which TRAAACE downloads straight from NVIDIA's website.
  • If your graphics card can't be used, the scan runs on the processor instead. The summary after a scan says which one it used.

Good to know

  • It replaces your normal TRAAACE. Your projects, tags and settings stay as they are. To go back, install the normal version from the Download section: nothing is lost.
  • You can keep both AI add-ons and switch with Runs on in the AI panel. TRAAACE restarts to switch.
  • Windows will warn you the first time, as with the normal version: click More info → Run anyway.
  • If the graphics card add-on won't load, install Microsoft's Visual C++ Redistributable (x64).

Windows only. This is a test version, so keep your photos backed up as usual.

Try it and send us your results

A few minutes of testing helps a lot. A folder of 50 to 100 photos is plenty.

Steps

  1. Install the download above and open TRAAACE.
  2. In the AI panel, click Set up AI…, choose NVIDIA graphics card, then Download and install.
  3. Open a folder and press Scan. When it finishes, the summary says something like “100 photos scanned in 0:45 on the graphics card”.
  4. To compare, set up the Standard add-on as well, choose Runs on: Processor, restart, and scan the same folder.

What to send us

  • Your graphics card and driver version (the top lines of nvidia-smi).
  • The scan summary for the graphics card, and for the processor if you compared.
  • Anything that went wrong: the message you saw, or a screenshot.
  • Email it to hello@traaace.ing. Thank you!
